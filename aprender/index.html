Cómo se usa
  • Cada habilidad del panel izquierdo es un diagrama. Tocala para verla.
  • Nodos = cards. Una línea A → B conecta A con B.
  • Arrastrá el puerto ● del borde derecho a otra card = conectarlas · a un lugar vacío = nuevo nodo conectado.
  • Arrastrá el puerto de entrada (borde izquierdo) = reconectar a otra card · a vacío = quitar la conexión.
  • Tocá una card = se abre su menú al costado. Tipo: concepto (algo para entender o recordar) o acción (algo para poder hacer, se entrena repitiendo).
  • Tocá una línea = seleccionarla para quitarla.
  • Arrastrá la card = moverla · Shift + arrastrar = mover con todo lo que sale de ella.
  • Doble clic = crear nodo / renombrar · ✎ renombrar · + nodo conectado · × borrar.
  • Arrastrá el fondo = mover · rueda o dos dedos = zoom · ⇶ reordenar acomoda todo en columnas.
  • Teclado: Tab nuevo nodo conectado · Supr borrar · Enter renombrar · Ctrl+Z / Ctrl+Y.
  • Los datos quedan en este navegador. Usá exportar para guardar una copia en JSON.
