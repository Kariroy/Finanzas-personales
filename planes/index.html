Tareas = mini-cards. Wire = dependencia (A→B = B depende de A).
— arrastrá el puerto ● (borde derecho) a otra card = dependencia · a vacío = nueva tarea dependiente
— arrastrá el puerto de entrada (borde izquierdo) = reconectar a otra card · a vacío = quitar la dependencia
— arrastrá la card = moverla · Shift+arrastrar = mover con todo lo que depende de ella
— clic en el círculo = por hacer → en curso → hecha · Shift+clic = pausar
— doble clic = crear / renombrar · Tab = nueva tarea dependiente
— clic en un wire + Supr = borrarlo · Supr = borrar tarea · rueda = zoom · arrastrar el fondo = mover
— Ctrl+Z / Ctrl+Y

Doble clic en cualquier lugar para crear la primera tarea.
