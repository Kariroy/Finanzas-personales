Tareas = mini-cards. Wire = dependencia (A→B = B depende de A).
— arrastrá el puerto ● (borde derecho) a otra card = dependencia · a vacío = nueva tarea dependiente
— arrastrá el puerto de entrada (borde izquierdo) = reconectar a otra card · a vacío = quitar la dependencia
— arrastrá la card = moverla · Shift+arrastrar = mover con todo lo que depende de ella
— clic en el círculo = por hacer → en curso → hecha · doble clic = pausar
— doble clic = crear / renombrar · Tab = nueva tarea dependiente
— clic en un wire + Supr = borrarlo · Supr = borrar tarea · rueda = zoom · arrastrar el fondo = mover
— puntito al lado del nombre = notas de la tarea (lleno = tiene notas)
— ☰ = mostrar / ocultar este panel
— ↻ Rutinas = checklist diario: tocá una rutina para marcarla; Semana / Mes para ver tu avance
— ◎ Objetivos = objetivos SMART: se miden con un número (anotás avances; revisión semanal o mensual) o con una rutina (se cuentan solos los días que la marcaste)
— ✎ Notas = apuntes: buscalos y filtralos por categoría; «⇩ exportar» descarga las que se ven en un archivo
— Ctrl+Z / Ctrl+Y
